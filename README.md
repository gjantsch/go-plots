# Graph explorations in golang

Some code with the solely purpose to test some ideias and concepts using tiny libraries.

Cmd folder holds a progression of implementations of a very basic and no so function renderer based on the study of the code presented on [
How Does OpenGL Work?](https://www.youtube.com/watch?v=Ffi-eKJWwuE) video.

Hopefully someday I'll get in the level of the [TinyRenderer](https://haqr.eu/tinyrenderer/) although I'm most likely to say that I'm pretty fulfilled with the current acomplishment.
